# Your Figma wireframe — checklist

Create an original Figma wireframe and export as `little-lemon-wireframe.jpg` in this folder.

- Top app header: lemon logo and profile avatar.
- Hero: Little Lemon / Chicago title, description, image, search input.
- Menu category pills: starters, mains, desserts, drinks.
- Scrollable food list: name, description, price and photo.
- Onboarding screen: first name, email, disabled/enabled Next states.
- Profile screen: avatar/initials, editable fields, save/discard/logout.

This document is not a substitute for the exported image required by Coursera.
